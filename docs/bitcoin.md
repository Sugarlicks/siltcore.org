# Why This Matters for Bitcoin

Bitcoin transactions are acts of authority, not merely technical events.

Every signature expresses intent, responsibility, and consequence. Yet most Bitcoin wallets treat all signatures as equivalent, collapsing different forms of authority into a single approval moment.

In practice, individuals often act in multiple capacities:

• personally
• as delegates
• as custodians
• under limited or temporary authority

When these distinctions are invisible, users can make irreversible mistakes, lose funds, or bind themselves in ways they did not fully understand.

SILT Core introduces primitives that make these distinctions explicit.

By formalising capacity, consent, delegation, and revocation, SILT provides a specification layer that Bitcoin tools can adopt to improve signing clarity and reduce catastrophic user error.

The project does not modify Bitcoin itself. Instead it defines semantic structures that wallet software, coordination tools, or higher-layer protocols can incorporate to align technical execution with how humans understand responsibility and authority.
